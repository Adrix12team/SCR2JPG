First of all, *thanks* for using SCR2JPG! If converted correctly, your screenshots should appear as if they were photos taken on the exact moment of the screenshotting, after updating the management file. If the file isn't in the detectable file name format, it will appear as if taken on the 1st of January, 2001.
Please report bugs if you encounter any! PRs and forks are welcome.
#### Features: 
- Automatic conversion from SD
- Option to choose to keep or remove original BMP pictures
  - If chosen to keep the originals, the original BMP won't be converted a second time
- 3D (top screen) screenshot support
  - 3D screenshots will be saved in the MPO format, which the 3DS uses for 3D pictures
